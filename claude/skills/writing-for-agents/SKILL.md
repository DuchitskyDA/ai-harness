# Тексты для агентов

Отвечай по-русски. Справочник, не процедура: прочитай и примени к своему тексту.

## Указатель решает всё

- Описание скилла и строка в своде - указатель. Агент читает его, не тело; сработает ли тело, определяет формулировка указателя.
- Ключевое слово - первым: то, по чему ищет сама ситуация (действие, объект), а не общие слова.
- Одна формулировка на одну ветку. Синонимы слей, иначе указатели соседей конкурируют.
- Пиши условие вызова («когда...»), а не пересказ содержимого.

## Цена текста

- Постоянно загруженное (свод, CLAUDE.md, описания скиллов) оплачивается токенами каждый ход. Режь жёстче, чем тело скилла, которое грузится по вызову.
- В постоянный текст - только то, без чего агент ошибётся до того, как успеет заглянуть в указатель.
- Строка, не менявшая поведения, - лишняя. Повтор одного правила в двух местах - тоже.
- Механическое правило (формат, запрет команды, путь) - в проверку (тест, lint, pre-commit), не в текст.

## Обязательное

- Если важное правило агент пропускает, сначала усиль формулировку указателя и его место.
- Встраивай текст в постоянный свод только когда усиление не помогло, и называй цену в токенах.

## Для человека

- Владельцу нужно знать, какие документы есть и когда их звать: свод - коротко, подробности - ссылкой (`POLICY.md`, скиллы).
- Не дублируй в нескольких документах: один источник, остальные - указатели.

## Форма

- Короткие предложения, императив, списки; пример только если без него неоднозначно.
- Что делать, а не чего избегать; запрет - с причиной одной фразой.
- Долговременное знание - в памяти Claude, не в тексте скилла.
